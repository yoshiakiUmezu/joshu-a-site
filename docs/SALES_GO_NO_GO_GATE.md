# 販売 GO / NO-GO ゲート

Last updated: 2026-10-07

## 目的

製品完成後に勢いだけで公開せず、かつ過剰な確認で公開を遅らせないため、販売可否を機械的に判定する。

判定は以下の3段階。

- GO: 販売準備へ進める
- CONDITIONAL GO: 条件を満たせば進める
- NO-GO: 販売/公開を止める

## 即NO-GO

次のいずれかがある場合はNO-GO。

### 法務・権利
- 商用利用不可ライセンス
- ライセンス不明の主要依存
- 無断利用素材
- 配布権が不明
- 第三者権利侵害の明確な懸念

### セキュリティ
- Critical / High相当の未解決脆弱性
- credential / secret 漏えい
- 安全にロールバックできない重大更新
- 個人情報を想定外に収集/送信する

### 品質
- 起動不能
- 主要機能が動かない
- データ破損リスク
- 必要な検証ゲート未実施
- 販売ページの説明と実製品が一致しない

### 事業
- 1件売るごとに赤字になる
- 継続固定費が基準シナリオ利益を恒常的に上回る
- 継続人手が利益構造を破壊する
- 資格/規制対応が必要なのに体制がない

## CONDITIONAL GO

以下は条件付きで進める。

- Minor / Moderate issueが残る
- サポート負担が未確定
- 一部プラットフォームのみ検証済み
- 価格未確定
- ストア審査待ち
- 本人確認待ち
- スクリーンショット/動画不足
- FAQ不足
- 署名/配布設定待ち

ルール:
- 問題に依存しない作業は継続
- その条件を満たすまでは公開だけ止める
- 全体停止しない

## GO条件

最低限以下を満たす。

### 製品
- 主要機能が利用可能
- 既知重大不具合なし
- 対応環境が明確
- バージョンが明確
- build artifactが存在

### 検証
- 必須CI成功
- 必要なE2E/device-E2E成功
- リリース対象に応じた配布確認
- rollback / update方針が明確

### 販売
- 価格候補あり
- 1件純利益が正
- 販売チャネル候補あり
- サポート先あり
- 返金/配布条件を説明可能

### 法務・権利
- 主要ライセンス確認済み
- 商用配布可
- 使用素材の権利確認済み

### 公開情報
- 一文価値
- 対象ユーザー
- 対応OS
- 価格
- CTA
- FAQ最低限
- known issue表記が必要なら記載

## 利益判定

### 悲観ケース
赤字でも即NO-GOではない。

### 基準ケース
- 直接利益が正であること
- 継続固定費と人手を含めても改善余地があること

### 楽観ケースのみ黒字
優先度を下げる。公開するなら学習目的を明示する。

## 人手負担ゲート

次のどれかに該当する場合はCONDITIONAL GO以上にしない。

- 毎日手作業が必要
- 毎販売ごとに人間操作が必要
- サポートを自動化できない
- 外部契約/交渉が継続的に必要
- 手動審査/更新が頻繁

## 公開判定フロー

1. 引き渡し仕様を受領
2. 即NO-GO条件を確認
3. CONDITIONAL項目を切り出す
4. 利益試算
5. 人手負担判定
6. 販売チャネル選定
7. ユーザーに必要判断だけ提示
8. GOなら24時間ローンチへ

## ユーザーに出す最終表示

例:

判定: CONDITIONAL GO

販売可能性:
- 製品品質: GO
- ライセンス: GO
- セキュリティ: GO
- 利益性: GO
- ストア本人確認: WAIT

ユーザー判断:
- itch.io先行公開を承認するか
- Steam Direct Feeを支払うか

この形式で、判断点を最小化する。

## 原則

- 「不明だから全停止」にしない
- 不明項目だけを局所ブロッカーにする
- 法務/セキュリティ/赤字構造は例外なく厳格に扱う
- 売れる保証ではなく、販売してよい状態かを判定する


## Terminal統合時の表現

GO / CONDITIONAL GO / NO-GO はOrchestratorの巨大な直書きstateではなく、versionedな `CommercialGateResult` として保存する。

最低限:
- decision
- blockers
- conditions
- warnings
- evidence
- evaluatedAt
- policyVersion

CONDITIONAL GOは「公開してよい」の意味ではなく、条件未達の公開系だけを止め、非公開作業を継続できる状態とする。

Gate ResultはGitHub正本へ保存し、AI会話状態だけに保持しない。
