# 販売・公開 実行ロードマップ

Last updated: 2026-10-06

## 目的

「誰が・いつ・どこで・何をするか」を固定し、製品完成から販売・改善までの引き継ぎロスをなくす。

## 役割

### ユーザー
担当:
- 重要な事業判断
- 価格最終承認
- 外部サービス契約
- 本人確認
- 公開/販売の最終承認
- 法務/税務など本人判断

原則:
- 手作業の調査・定型更新は担当しない
- 判断だけ返す

### 販促窓（このChatGPT）
担当:
- 販売先比較
- 最新手数料/審査条件
- 価格候補
- 損益試算
- 公開順
- KPI設計
- 売れない場合の診断
- 販促チャネルの役割整理

### ホームページ側
担当:
- joshu-a.com のHTML/CSS実装
- 製品ページ
- CTA
- metadata
- JSON-LD
- sitemap
- 表示/アクセシビリティ
- 公開チェック

### A.I. TERMINAL / dot
担当:
- 製品の製造
- テスト
- ビルド
- リリース候補作成
- 既存ルール内の自動検証
- 必要情報の出力

### 外部チャネル
- itch.io: ゲーム/DL製品
- Steam: 適合するゲーム
- note: 背景/一次情報
- X: リリース/更新/短いデモ
- Search Console/Bing: 検索可視性

## フェーズ別の実際の流れ

### Phase 0 — 製品未完成（今）
**誰:** 販促窓
**どこ:** joshu-a-site / 公開情報調査
**何をする:**
- 販売ルール整備
- チャネル条件更新
- 価格ルール整備
- KPI/診断ルール整備
- 公開時テンプレ整備

**ユーザー作業:** 原則なし

### Phase 1 — 製品が「販売可能候補」になった瞬間
**トリガー:** A.I. TERMINAL / dot が販売候補を完成させる

**ユーザー → 販促窓**
伝えること:
- 「製品できた」
- 製品名
- 一文説明
- 対応OS
- 無料/有料の希望
- 既知の公開先候補

**販促窓**
- 最新チャネル条件を再確認
- 価格候補
- 手数料
- 月3万/5万への必要販売数
- 公開順
- 採用/見送りチャネル
を提示

**ユーザー**
- 価格
- 販売先
- 公開可否
だけ承認

### Phase 2 — 公開素材作成
**販促窓 → ホームページ側**
渡すもの:
- 製品名
- slug
- 一文価値
- 対象者
- 価格
- OS
- CTA先
- FAQ
- 販促コピーの骨子

**ホームページ側**
- 製品ページ実装
- metadata / JSON-LD / sitemap
- 公開チェック

**A.I. TERMINAL / dot**
- ビルド
- 配布物
- テスト証拠
- バージョン
- リリースノート
を準備

### Phase 3 — 販売チャネル準備
**販促窓**
- itch.io / Steam / note / X のうち必要なものだけ選択
- チャネル別説明文・タグ・UTM設計
- ストア要件確認

**ユーザー**
- 契約/本人確認/支払いが必要な箇所のみ対応
- 最終公開承認

### Phase 4 — 公開
**ホームページ側**
- joshu-a.com 公開

**外部チャネル**
- 採用したストア/媒体を公開

**販促窓**
- URL整合
- CTA整合
- 価格整合
- UTM
- sitemap/Search Console確認

### Phase 5 — 72時間
**販促窓**
- 流入
- CTA
- 購入/DL
- 問い合わせ
を確認

**ユーザー**
- 原則なし
- 重大問題/価格変更などのみ判断

### Phase 6 — 7日
**販促窓**
- ボトルネック診断
- 改善案を1つ選ぶ

**ホームページ側 / A.I. TERMINAL**
- 必要な改善を実装

### Phase 7 — 30日
**販促窓**
- 月間純利益
- Pro費用回収
- 人手負担
- 継続/改善/停止
を評価

**ユーザー**
- 次の製品への投資判断
- 上位Pro等の固定費判断

## ユーザーが実際にやることだけ抜粋

製品完成時:
1. 「製品できた」と言う
2. 価格/販売先の候補から選ぶ
3. 外部サービスの本人確認・契約が必要なら対応
4. 公開を承認する

公開後:
5. 重大判断が来た時だけ答える

それ以外は、販促窓・ホームページ側・A.I. TERMINAL/dotへ分離する。

## SLA目標

- 製品完成 → 販売方針決定: 6時間以内
- 販売方針決定 → 製品ページ/ストア準備: 12時間以内
- 条件が揃っている製品: 完成から24時間以内に販売開始
- 外部審査がある場合: 申請まで24時間以内

## 停止条件

次の場合のみ販売フローを止める:
- セキュリティ重大問題
- 権利/ライセンス不明
- 法務/規制懸念
- 決済/署名/本人確認未完了
- ユーザーが公開停止を指示
- 製品品質ゲート未達

それ以外の局所問題は、独立作業を継続する。
