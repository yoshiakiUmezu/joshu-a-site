## 監査結論

- 全10件に固有の `<title>` と meta description があり、現行のOG title/description と一致。
- SEO用タイトルの一斉置換は不要。現行タイトルのほとんどは単元名と操作内容を表している。
- 優先修正は「算数/数学の対象学年表現」、「歴史年表の内容特定」、「曖昧な動詞」のみ。
- 検索順位・検索ボリューム・CTRは未取得。以下は検索需要の実測順位ではなくコピー監査の推奨度。
- 大量の同義語追加やH1の画一化はしない。検索語を詰め込みすぎない。

## 説明文の提案・確認点

### linear-function
現行: 一次関数 y=ax+b の傾きaと切片bを動かし、直線・切片・傾きの変化をグラフで確かめる無料の算数Web教材です。

候補: 一次関数 y=ax+b の傾きと切片を自分で変えて、直線がどう動くかをグラフで確かめる無料の数学Web教材です。

### proportion
現行: 比例 y=ax と反比例 y=a/x の値やグラフを動かして比べる無料算数教材です。比例定数とxの範囲を確認できます。

候補: 比例 y=ax と反比例 y=a/x の違いを、値やグラフを変えて比較できる無料数学教材です。表示範囲や式の対応を確かめられます。

### probability
現行: サイコロの出目を操作して、確率と試行回数による結果のばらつきを体験する無料Web教材です。

注意: 「出目を操作」は偶然の出目を任意に決められる意味にも取られるため、実装の操作仕様を確認。複数回の試行が可能なら「サイコロを繰り返し振り、試行回数によって出目の割合が変わる様子を確かめる無料教材です。」など、実装と一致する文言を採用。現時点で断定変更しない。

### japan-and-world-history
現行: 弥生時代から大正時代まで、日本史の出来事と同時代の世界を時系列で見比べる無料歴史教材です。年代の幅や史料上の注意も確認できます。

判断: 良好。修正不要。titleの改善候補はあくまで検索結果で内容を明確にするため。H1「日本のあの頃、世界では？」は保持推奨。

### その他6件
point-p / speed-distance-time / current-voltage / light-reflection / moon-phases / geometry-nets は現行title・descriptionを維持。誇張・未確認学習効果の追加を避ける。

## 実装指示（ホームページ窓）

1. 当該ページの実装機能を照合し、文言が操作に対応するか確認する。
2. 優先対象は `linear-function` と `japan-and-world-history`。必要なら `proportion`、`probability` を同じ小規模PRに含める。
3. `<title>`、meta description、OG/X title/description、JSON-LDの記述が相互に矛盾しないよう更新する。H1変更は原則不要。
4. URL slug、canonical、sitemapのURL、公開中の機能や本文の内容は変更しない。
5. 最新mainの競合作業・PRを確認し、専用ブランチで実装。main直push・無承認merge/deployは禁止。
6. 変更後はrelease系テスト、メタデータ整合、プレビュー表示を確認。
7. 公開後の効果判定はSearch ConsoleのURL別表示・クリック・クエリで行う。ただしデータが少なければ結論を保留。
