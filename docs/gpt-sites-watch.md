# GPT Sites / ChatGPT Sites 監視項目

助手A公式サイト `https://joshu-a.com` は現在 GitHub + Cloudflare Pages を本番基盤として運用する。

ChatGPT Sites / GPT Sites は今後の代替・併用候補として監視し、次の条件が満たされた場合に移行可否を再評価する。

## 現状判断

- 現時点では Cloudflare Pages を継続する。
- 既存の GitHub 運用、独自ドメイン、SEO/OG、`_headers`、release checker、製品ページ運用を捨ててまで移行する根拠はまだない。
- Sites の存在だけを理由に再構築しない。

## 再評価トリガー

OpenAI公式情報で、以下のいずれかに実質的な改善があった場合に再評価する。

- 独自ドメイン運用
- SEO / canonical / sitemap / robots / OG / X card の制御
- HTTPヘッダーやリダイレクト等の公開制御
- GitHubとの同期・import/export・コード所有性
- 既存サイトからの移行容易性
- 製品ページなど複数ページの運用
- 公開上限・利用制限
- 料金
- ホスティング可用性・依存リスク
- 計測や外部導線との連携

## 移行判断の最低条件

移行案を検討する場合も、最低限以下を満たすこと。

1. `joshu-a.com` を維持できる。
2. 検索・SNS共有・製品ページの現行要件を下げない。
3. GitHub上の正本、または同等以上に移行可能な形で成果物を保持できる。
4. OpenAI側の仕様変更でサイト運用が強く拘束されない。
5. 現行Cloudflare Pagesより、運用工数・費用・自動化のいずれかで明確な利点がある。

## 課題

- [ ] GPT Sites / ChatGPT Sites の公式仕様変更を継続監視する。
- [ ] 上記再評価トリガーに該当する変更が出た場合、Cloudflare Pagesとの比較表を更新する。
- [ ] 移行メリットが明確になった場合のみ、別環境で試作して本番移行可否を判断する。

監視結果に意味のある変更がない限り、サイト構成は変更しない。
