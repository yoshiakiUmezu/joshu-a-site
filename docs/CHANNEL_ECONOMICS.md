# 販売チャネル基準表

Last verified: 2026-10-06

## 目的

製品完成後に販売先をゼロから調べ直さないため、公開条件・固定費・人手負担・自動化適性を先に整理する。

数値や規約は変わるため、実製品の販売判断時に必ず再確認する。

## 現時点の基準

### joshu-a.com / 直配布

**役割:** 母艦・正本・最優先の導線。

- 独自サイト側の追加プラットフォーム手数料: なし
- Discovery: 弱い。検索・外部流入を別途作る必要あり
- 人手負担: 低〜中
- 自動化適性: 高
- 向くもの: Windowsソフト、Web製品、公式情報、サポート、他ストアへの導線
- 注意: 実際の決済を自前で持つ場合は決済事業者・税務・返金対応を別途評価する

**暫定判断:** 全製品で採用。販売そのものを別チャネルに置く場合でも正本ページは維持する。

### itch.io

**役割:** ゲーム、DL可能な小規模ソフト、実験作の販売/配布とDiscovery。

2026-10-06確認:
- Open Revenue Sharingで、itch.ioへのRevenue Shareを販売者が0〜100%で設定可能
- 公式例のデフォルトは10%
- これとは別に決済事業者手数料等が差し引かれる
- Pay-what-you-wantにも対応

**Discovery:** 中
**人手負担:** 低
**自動化適性:** 高
**初期固定費:** Steamより低い
**向くもの:** indie game、小規模DLソフト、無料+支援型

**暫定判断:** 初期商品の有力チャネル。ゲームではSteamより先に検証する価値が高い。

### Steam

**役割:** 十分な完成度・市場適合があるゲームの大規模Discovery/販売。

2026-10-06確認:
- Steam Direct Fee: 1製品あたり100 USD相当
- 返金不可。ただしAdjusted Gross Revenueが1,000 USD以上になると後の支払いで回収対象
- 初回付近のタイトルではDirect Fee支払いからリリースまで30日待機
- Coming Soonページを最低2週間公開する必要あり
- Store/build reviewは通常1〜5日
- 銀行・税務情報・本人確認が必要

**Discovery:** 高
**人手負担:** 中〜高
**自動化適性:** 中
**初期固定費:** あり
**向くもの:** 市場性があり、ストアページ・トレーラー・継続更新に耐えるゲーム

**暫定判断:** 「最初から全ゲームをSteam」にはしない。市場性が見込める作品のみ採用。

### Google Play

**役割:** Androidアプリの一般ユーザー向けDistribution。

2026-10-06確認:
- 2023-11-13以降に作成された新しい個人用Developer Accountは、製品版アクセス前にクローズドテスト要件あり
- 12人以上のテスターが14日間連続でopt-inした状態が必要
- 条件達成後、製品版アクセス申請
- Googleによる審査は通常7日以内だが、それ以上かかる場合あり
- 本人確認等も必要

**Discovery:** 高
**人手負担:** 高（特に新規個人アカウント）
**自動化適性:** 低〜中
**向くもの:** Androidストアでの存在が販売上重要な製品

**暫定判断:** 人手最小化方針と衝突しやすい。Web/Windows/itch.io等で代替できるなら初期優先度を下げる。

### note

**役割:** 販売チャネルというより、説明・背景・一次情報から製品へ送客するDiscoveryチャネル。

2026-10-06確認:
- note社開示ではクリエイター売上に対する平均テイクレートは約17%
- プラットフォーム利用料は基本10%（定期購読マガジンは20%）
- 事務手数料は決済手段により変動
- 無料コンテンツがDiscoveryとして機能する構造

**Discovery:** 中
**人手負担:** 中。ただし自動化対象にできる
**自動化適性:** 中
**向くもの:** 制作背景、問題解決、検証結果、一次情報

**暫定判断:** 主販売先にはしない。joshu-a.com製品ページへの導線として使う。

## チャネル優先ルール

### Software
1. joshu-a.com
2. 直配布 / Web
3. itch.io（適合する場合）
4. note / XでDiscovery
5. ストアは期待収益が人手負担を上回る場合のみ

### Game
1. joshu-a.com
2. itch.io
3. Steam（市場性と完成度が十分なら）
4. note / XでDiscovery

### Android
1. Web/PWA等で代替可能か確認
2. 直配布が許容される製品か確認
3. Google Playでなければ売れない理由が明確な場合のみ優先度を上げる

## 更新トリガー

次の場合はこの表を再調査する。

- 実製品の販売チャネル決定時
- プラットフォーム規約/手数料改定
- Google Playの個人アカウント要件変更
- Steam/itch.io/noteで販売実績が出た時
