## 決定事項 — 最初のプロフィールと固定ポスト

1. プロフィールにはブランド名、ソフトウェア/ゲーム/無料知育コンテンツの制作、コピー、公式サイトを簡潔に記載する。
2. 固定ポストは **自己紹介 ＋ A.I. TERMINAL起動時の既存ロゴアニメーション動画** を採用する方針。
3. 投稿本文には、何を作るブランドか、A.I. TERMINALは開発中であること、無料知育コンテンツは既に体験できること、公式サイトへのリンクを明示する。誇張しない。
4. 当面の固定ポストの行き先は公式トップでもよい。単一教材の紹介投稿は原則として該当教材の正式URLへ直接リンクする。
5. 知育教材公開中の暫定的な自己紹介固定ポストとし、正式な主要製品が公開されたら固定内容の再検討を販促窓に提案する。
6. 動画の最適化はX公式の最新仕様を確認し、短く、無音でも理解できる構成を優先する。具体的な秒数・形式を固定仕様として扱わない。

### ロゴ・映像の絶対条件

- 正本のロゴは A.I. TERMINAL repo `yoshiakiUmezu/ai-terminal` の `assets/brand/assistant-a/master-original.jpg`（要所在確認）。
- **形状、比率、線、構造を変更してはいけない**。色変更は可。生成AIによるロゴ再解釈・描き直しで代用しない。
- **起動アニメーションの実装・使用権利・収録方法を確認**し、元のアニメーションから映像素材を抽出する。所在不明なら調査し、存在を捏造しない。
- フォント・画面表示・音声・個人情報・機密情報・ライセンスなど投稿素材の安全性を確認する。
- 新規収録や変換でも、アニメーションが崩れたりロゴが改変されたりしていないことを確認する。

## 安全・GitHubルール

- メインの情報源はGitHubの正本文書。会話履歴・AIの推測を恒久的な状態管理に使わない。
- リポジトリ更新は **最新main + 進行中PR確認 → 担当専用ブランチ → Draft PR**。main直接push、force push、他担当のブランチ再利用は禁止。
- `joshu-a-site` はmainとCloudflare Pages本番公開が連動している。無承認mainマージは不可。
- 外部アカウントのプロフィール変更、固定ポスト、投稿、公開URLの変更、有料サービス利用はユーザー承認を得る。
- 人手負担最小化を優先。毎日投稿や有料自動化を前提にせず、実績に基づいて少数投稿する。
- X投稿データの正本化にあたって、アクセス用トークン、ログイン情報、個人情報は記録しない。
- X担当が運用を開始したら、このファイルのステータスと未完了項目を更新し、他の窓が同じ状態を読めるようにする。
